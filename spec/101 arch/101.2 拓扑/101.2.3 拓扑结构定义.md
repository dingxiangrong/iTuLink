## 101.2.3 拓扑结构定义

iTuLink 体系整体拓扑为「外部业务抽象层 — 桥接适配层 — 内核智能层」三级嵌套架构：

**外层：外部业务抽象层** UPP 作为抽象模型，承载 Capability 业务能力抽象、Action 业务操作抽象，以及本域会话、权限管理。

**中层：桥接适配层** CC 作为唯一桥接中间件，完成抽象模型到真实外部对象的映射转换，打通内核智能层与外部业务抽象层。

**内层：内核智能层** 完整内核模块集合：SE、SV、CDT、PT、SAM。 内置 SE：直接耦合 SV，无需 PT； 剥离式 SE：终端独立运行，通过 PT 建立设备连接，仅打通通讯通道接入 SV。

**层级单向依赖：** 内核生成指令 → 桥接层执行映射转换 → 外部业务抽象层对接真实外部对象

```
                    iTuLink 意图链接
        ┌───────────┬───────────┬───────────┬───────────┐
        SE主权入口              UPP单元业务平台
                                │
                                └─ CC 能力容器

        SV端侧自治域
        │
        └─ PT 枢接口

        CDT 认知推演树
        SAM 主权聚合记忆
```
