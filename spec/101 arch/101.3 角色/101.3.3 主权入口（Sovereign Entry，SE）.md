## 101.3.3. 主权入口（Sovereign Entry，SE）
### 定义

SE 是主权主体和 iTuLink 体系交互界面，是主权主体意志与感知的唯一载体，负责接收主权主体的输入、呈现体系输出结果。分为**内置 SE**与**独立 SE**两种部署形态：

1. 内置 SE：默认形态，直接连接 SV，不经过 PT；

2. 独立 SE：可脱离内核部署在终端设备，通过 PT 建立设备级连接接入 SV。独立SE 不绑定固定硬件，支持多形态、多点接入。
### 职责

- 输入采集：向主权主体提供文字、语音、附件、多模态数据等输入能力。

- 输入上送：将主权主体输入的数据向上提交给 SV 层。

- 推演支撑：响应 SV 的认知推演过程，为主权主体风险抉择交互提供支撑。

- 结果呈现：接收并响应 SV 的认知推演结果，提供渲染能力，向主权主体呈现。

- 对话控制：对已发起的对话提供控制能力，如取消对话（cancel）。

- 会话视图管理：维护本地会话列表，响应用户切换历史会话的操作，经由 SV 完成会话复用。

- 引导信息呈现：承接系统下发的各类提示信息，向用户展示指引内容。
### 对接场景

SE 面对不同能力，交互表现分为两种场景；CC 仅作为桥接载体，自身不实现 UI 渲染。

1. 对接自带 UI 的能力 UI 渲染逻辑由能力自身实现。SE 仅作为操作抓手，类比鼠标，只向能力投递点击等交互动作，不负责界面绘制与画面渲染。

2. 对接无 UI 的能力 能力本身不提供用户界面。SE 同时承担键鼠输入与结果输出载体，充当 Shell 外壳，完成指令输入，通过对话框回显执行结果。

> 说明：以上两种对接场景，对内置 SE、独立 SE 两种部署形态全部适用，与部署形态无关。
### 约束

- 主权入口仅做人机输入采集、现象渲染展示，无业务逻辑、无认知推演、无状态存储。

- 严格遵从通路规则：不直连 CC 能力容器，所有交互必经 SV 端侧自治域中转。

- 具备体系观察、干预、暂停、否决权限，不可篡改内核推演与底层架构逻辑。

### 实例

客观实例：设备本地屏幕、控制台、服务器管控终端、手机、PC、远端终端；

形态分类：应用操作界面、独立操作终端。
