## 101.3.5. 认知推演树（Cognition-Deduction-Tree，CDT）
### 定义

认知推演树：全域总对话事件路由、全局任务规划内核，承载主权对话管理、认知推演、任务路径规划、外部智能引擎路由协调。以归一化客观现象、业务目标、SAM 记忆素材为输入，**在已经完成建模的推演树骨架之上开展推演运算；推演树骨架的建模建树属于外部前置能力，不属于 CDT 本体职责**，推演可行执行方案，输出结构化意图指令交由 SV 落地调度（不直接操控 CC）。

> 注：组件内部推演运算的具体算法逻辑属于工程实现层，本架构规约不作细节约束。
### 职责

- **主权对话管理**：维护对话上下文，判定人机会话主权归属，管控人机主导权切换，维系对话状态流转。

- **认知推演**：结合业务目标、对话上下文、及SAM 主权记忆、全域能力状态，做多分支任务推演，生成多条候选执行路径。

- **任务路径规划**：筛选候选路径，自主制定意图，生成有序原子任务序列并逐条输出结构化意图指令；意图自主制定与指令迭代闭环，直至任务目标达成。

- **外部智能路由协调**：按需调度外部 LLM 等智能引擎；约束外部模型输入载荷，接收返回内容，将自然语言结果转换为本体系结构化意图，支撑任务路径规划。

- **能力状态感知**：消费 SV 转发的归一化客观现象，作为推演的事实输入。

### 约束

- CDT 不得直连 SE、UPP、CC，跨顶层组件交互全部经由 SV 中转；仅与 SAM 内部双向耦合读写记忆。

- CDT 仅输出意图规划，不直接寻址、驱动 CC；指令投递至 SV，由 SV 完成权限、能力健康校验后执行调度，形成架构制衡，防止认知层越权操控执行层。

- CDT 不负责能力生命周期管理、服务注册发现；不定义业务规则、权限真值；不执行原子业务能力。

- CDT **不承担推演树骨架的建模建树工作**；不负责能力生命周期管理、服务注册发现；不定义业务规则、权限真值；不执行原子业务能力。
### 实例

客观实例：agent。

### 示例：

示例：浏览器 Web 前端 SE，浏览器内部署 Web-SV；后端部署 CDT、SAM、KB-CC 知识库容器。用户提交指令：检索知识库，找到 D 盘归档文档摘要并展示。

1. SE 采集用户原始请求，提交至 Web-SV；

2. Web-SV 完成本地接入校验，将事件中继转发至 CDT；

3. CDT 读取 SAM 主权记忆，执行认知推演与任务拆解，生成结构化意图指令下发至 Web-SV；

4. Web-SV 校验指令，寻址转发至后端 KB-CC；

5. KB-CC 执行检索，产出客观现象回传给 Web-SV；

6. Web-SV 归一化结果，回送 CDT；

7. CDT 依据返回事实判定任务收敛，或继续生成下一轮意图指令迭代推演；任务完成后输出面向用户的引导指令；

8. Web-SV 将最终报文中继至 SE，完成页面渲染展示。
