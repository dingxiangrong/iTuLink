## 101.3.6. 主权聚合记忆（Sovereign Aggregate Memory，SAM）
### 定义

SAM 是本体系唯一认知资源内核，是全域基线资产、公理体系、推演成果、记忆时序沉淀的标准化管理本体。

该内核为 SAM 组件出厂内置核心能力，与 CDT 推演内核一一配套、原生共生，为所有推演行为提供标准化资源底座。
### 职责

- **最小认知资产单元管理**：以单条公理、单份基线图纸、单条约束定义、单套推演成果为最小独立资产单元，单资产独立生命周期管理，互不耦合、独立迭代。

- **资产版本全域管控**：每份认知资产分配唯一标识与独立版本谱系；单点资产更新仅迭代自身版本，不牵动全域基线体系；历史版本永久留存，支持版本回溯与版本对比。

- **全局句柄索引寻址**：所有资产统一生成体系唯一句柄；对外提供句柄精准寻址、按需加载能力；支撑 CDT 节点轻量化引用，实现「树与资产完全解耦」。

- **多源认知记忆聚合**：聚合历史推演轨迹、对话上下文、客观现象、主权偏好多源认知数据；结构化沉淀时序记忆，维持人格连续性与体系经验复利。

- **资产有效性合规校验**：校验 CDT 节点资产引用的版本有效性、边界匹配性；自动识别失效资产、过期约束、冲突定义；支撑 CDT 异常定位的资源层依据输出。

- **推演成果资产入库**：CDT 收敛完成的完整推演树，自动作为高阶认知资产入库 SAM；新资产生成新句柄、新版本，可复用至后续全域推演。
### 约束

- SAM 全程保持被动响应特性，严格遵从 101 约束：不主动推送、不主动干预推演。

- 仅响应 CDT 读写请求，为推演过程提供资源支撑、为体系生长提供资产沉淀。

- 所有资产变更、版本迭代，仅联动对应 CDT 分支局部重算，不破坏全域推演成果。

- 记忆数据归属主权主体，不托付公域。
