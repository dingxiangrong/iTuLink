## 101.3.7. 枢接口（Port，PT）
### 定义

隶属于 SV，作为**独立主权入口** 的外部接入端口。提供多层次通信能力接入，负责建立人与体系之间的连接链路、适配人的接入方式、收敛独立 SE 接入流量。

### 职责

- **连接建立**：管理独立 SE与 SV 之间的连接建立与维护。

- **接入适配**：适配不同独立 SE接入方式的通信协议，向上对 SV 提供统一的接入抽象。

### 约束

- 附属 SV，不可独立存在。

- 仅服务 SE 接入，不涉及 CC 能力接入（CC 接入由 SV 能力接入职责覆盖）。

### 实例

客观实例：微信、蓝牙、WiFi 直连、蜂窝网络等独立 SE与体系之间通信的手段。
