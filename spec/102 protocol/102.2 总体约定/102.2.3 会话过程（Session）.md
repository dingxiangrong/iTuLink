### 102.2.3 会话过程（Session）

Session 代表一套主权主体在一个 UPP 的访问过程。

1. 通过 session-in 完成会话登入建立；通过 session-out 执行会话登出销毁。

2. 代表某个主权主体在一个 UPP 中的访问过程，是身份、权限、实例上下文的最小管控单元。会话绑定确定主权主体身份与权限上下文，并统管其归属 CC 的能力上下文；会话销毁，则该主权下全部实例上下文失效。

3. 元语报文必须携带合法 Session 标识；无合法 Session 标识的跨模块调用判定为非法报文。

4. CC 内部语义域绑定所属 Session 主权；禁止跨 Session 穿透访问语义域内部资源。
