### 102.2.5 Chat 过程（Chat）
Chat 过程隶属于 Conversation，是上下文体系里**最小独立执行单元**，对应单次用户意图发起的任务。
一个 Chat 任务生命周期内，可顺序下发多条 mid-instruct，最终由 fin-instruct 标记任务终结。
中断、取消操作仅作用于当前 Chat，不会销毁上层 Conversation 与 Session。
Chat 关闭后，Conversation 内的持久能力实例、分组上下文保留，可供同 Conversation 下其他 Chat 复用。
