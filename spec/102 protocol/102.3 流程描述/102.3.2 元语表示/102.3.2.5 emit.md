# 102.3.2.5 emit（接口事件广播元语｜单向无应答｜状态通知）

**元语签名**：emit(event-path: PathExpr, payload: Payload, ctrlMap?: CtrlMap) -> void

**描述**：emit（接口事件广播元语｜单向无应答｜状态通知）。emit 为单向广播通道，仅用于生命周期事件、状态变更事件、就绪通知事件。单向广播、不等待应答、无返回配对、不参与业务调用链路，专用于容器状态、状态、能力状态的顶层状态推送。emit 面向多个订阅监听角色分发，消费方收到即处理；发送方发完即结束，不等待任何业务反馈。emit 对业务对等端不产生任何应答包；消息总线 / 中间件在传输层的 ack 属于技术实现细节，不在本语义契约定义范围内。

**元语层组包规则**：元语层自动完成消息组包，生成 meta、header 两段；业务侧仅传入 event-path、payload，可选传入 ctrlMap，无需手动填充 meta、header 字段。meta 内 `src_crid` 取自当前模块 CRID；`dest_crid` 不填充，由总线订阅匹配机制处理。

**补充**：
header 新增 deadline，表示事件有效截止时间；deadline = 0 表示不限制。deadline 值由 ctrlMap 内配置项映射填充；ctrlMap 不传时，deadline 默认等于 0。

**请求报文（emit）**

```
{
  "meta": {
    "primitive": "emit",
    "src_crid": "string",
    "path": "<由具体接口定义>",
    "version": "1.0"
  },
  "header": {
    "trace_id": "string",
    "timestamp": "long",
    "deadline": "long"
  },
  "payload": {
    "<业务参数由具体 path 定义>"
  }
}
```

**响应**：emit 属于广播类接口事件，契约层面无应答报文。

**约束**：
**meta 字段定义**：

- primitive：元语原语类型，固定为 `"emit"`。
- src_crid：本条报文发送端点 CRID，emit 报文发送方为当前业务模块，由元语层自动填充，业务侧无需传入。
- path：事件路径表达式，用于事件订阅匹配。
- version：元语协议版本。

**header 字段定义**：
emit 报文 header 不包含 correlation_id。

- trace_id：事件追踪标识。
- timestamp：报文生成时间戳。
- deadline：事件有效截止时间，单位统一为毫秒；值为 0 表示无时间限制。该字段由入参 ctrlMap 映射生成，ctrlMap 不传默认填充 0，元语层读取并写入报文 header。消费方处理事件前校验 header.deadline，若当前时间已超过 deadline，直接丢弃本条事件，不执行业务消费逻辑。

入站 emit 事件报文抵达组件，进入该模块 on (事件报文) 统一入口，识别元语类型后执行业务消费逻辑，不输出应答报文。
emit 为一对多广播分发，区别于 call、post、notify、return 的点对点定向通信。
payload 承载事件业务数据，内部结构由具体 path 接口文档定义。

> ctrlMap 说明：CtrlMap 为可选控制参数字典，承载链路控制类配置，deadline 是其中一项配置项；后续可在 ctrlMap 扩展其他控制参数，元语层自动映射至报文 header。
