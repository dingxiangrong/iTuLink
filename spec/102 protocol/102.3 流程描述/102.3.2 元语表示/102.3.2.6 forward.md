# 102.3.2.6 forward（路由转发元语｜透传转发｜身份保留）

**元语签名**：forward(msg: Msg, destFp: Crid) -> SysMsg
**描述**：forward（路由转发元语｜透传转发｜身份保留）。forward 为路由专用元语，仅由 SV 路由实体使用。作用为原样转发原始事件，SV 仅做路由中转，不作为事件发送方；完整保留原始事件的发送方身份、trace_id、eventId、事件全部原始载荷，不修改事件本体内容。

区分：msg.meta.path 是原始事件自身业务 path（PathExpr）；新增入参 destFp: Crid 代表 SV 选定的路由出口（interface / 通道）标识，用于选择报文从哪个对外出口送出。二者相互独立。destFp 仅用于 SV 内部出口选择，不写入转发出去的事件报文。

**元语层组包规则**：元语层自动完成消息组包，生成 meta、header 两段；SV 仅透传原始报文内容，不自行改写原始 msg 的 meta、header、payload。转发报文的 meta.path 沿用原始 msg.meta.path，destFp 参数仅用于 SV 选定转发出口，不会写入转发出去的事件报文，原始事件报文结构完整不变。

**请求报文**：

```
{
  "meta": {
    "primitive": "forward",
    "path": "<取自传入Msg.meta.path>",
    "version": "1.0"
  },
  "header": {
    "trace_id": "string",
    "timestamp": "long"
  },
  "payload": {
    "<继承原始报文payload>"
  }
}
```

**本地构造返回报文**

```
{
  "meta": {
    "primitive": "none",
    "src_crid": "string",
    "dest_crid": "string",
    "path": "<复用请求的path>",
    "version": "1.0"
  },
  "header": {
    "msg_id": "string",
    "correlation_id": null,
    "timestamp": "long",
    "deadline": "long",
    "ret_code": "string",
    "ret_msg": "string"
  },
  "payload": {
    "biz_code": "0",
    "biz_msg": ""
  }
}
```

**约束**
**meta 字段定义**：

- primitive：元语原语类型，forward 请求报文固定为 `"forward"`；本地构造返回报文 primitive 固定为 `"none"`。
- src_crid：本条报文发送端点 CRID，forward 报文发送方为 SV 路由实体，由元语层自动填充，业务侧无需传入。
- path：取自传入 Msg.meta.path，沿用原始事件业务路径。
- version：元语协议版本。
**header 字段定义**：
- trace_id：继承原始事件追踪标识。
- msg_id：本条返回消息实例唯一标识。
- correlation_id：forward 请求报文、forward 本地构造返回报文，correlation_id 固定为 null。
- timestamp：报文生成时间戳。
- deadline：沿用前面元语返回报文字段规范。

使用主体限定：forward 仅限 SV 路由实体调用，其余模块禁止使用 forward 元语。
SV 仅作为路由中转角色，不修改事件本体内容，保留原始事件发送方身份、trace_id、eventId 与全部载荷，维持全链路追踪连续性。
destFp: Crid：路由出口标识，承载 SV 对外接口编号，供 SV 选择转发出口；destFp 仅在 SV 内部使用，不会写入被转发出去的事件报文，原始事件报文结构完整不变。
forward 不新增、不生成新业务事件，不追加业务应答，仅完成事件透传。forward 的本地构造返回报文禁止携带任何业务载荷；ret_code 与 ret_msg 仅表征报文解析、转发入队状态，不代表业务执行成败。
本地构造返回报文 header.correlation_id 原样复制请求报文的 correlation_id；返回报文生成独立新 msg_id。
原始事件是什么类型（call/post/emit），转发后仍然维持原元语类型不变。

> ctrlMap 说明：CtrlMap 为可选控制参数字典，承载链路控制类配置，deadline 是其中一项配置项；后续可在 ctrlMap 扩展其他控制参数，元语层自动映射至报文 header。
