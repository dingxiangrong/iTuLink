### 102.3.3.2 会话就绪通知

1. UPP 内部完成登录校验、身份确权、会话实例构建

2. UPP emit session-event(session-in) 广播会话就绪事件

3. SV on session-event(session-in) 监听会话就绪事件

【此处：SV 调用upp-meta-get、upp-cc-enum、 cc-cap-enum 获取能力列表，调用 cc-meta-get 获取容器元数据，构建会话能力空间，同步至 CDT】

4. SV emit session-event(session-in) 推送至 SE

5. SE on session-event(session-in)，进入可交互状态
