### 102.3.3.3 会话终止通知

1. UPP 内部执行会话关闭、实例销毁

2. UPP emit session-event(session-out) 广播会话销毁事件

   CC销毁本地上下文，CC不依赖SV，由UPP&CC的集成决定。

3. SV on session-event(session-out) 监听会话销毁事件
   
   【此处：SV 本地销毁会话能力空间，同步 CDT 回收对应会话上下文】

5. SV emit session-event(session-out) 推送至 SE

6. SE on session-event(session-out)，结束交互状态
