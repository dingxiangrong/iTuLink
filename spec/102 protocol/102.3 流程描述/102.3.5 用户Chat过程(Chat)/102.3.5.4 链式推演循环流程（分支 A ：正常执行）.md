### 102.3.5.4 链式推演循环流程（分支 A ：正常执行）

21.CDT：post chat-event (event_type=chat_stream) → SV，回填 session_id，推送实时分片内容

22.SV：on chat-event (event_type=chat_stream)，SV 执行 on 元语捕获事件，进入路由处理

23.SV：forward chat-event (event_type=chat_stream) → SE，SV 执行 forward 元语透传流式分片事件

24.SE：on chat-event (event_type=chat_stream)，【SE内部】接收实时分片内容，完成界面流式渲染展示

25.CDT：post chat-event (event_type=mid_instruct) → SV，CDT 执行 post 元语，投递中间推演机器指令事件，回填 session_id

26.SV：on chat-event (event_type=mid_instruct)，SV 执行 on 元语捕获事件，进入路由处理

27.SV：forward chat-event (event_type=mid_instruct) → CC，SV 执行 forward 元语中转转发原始指令事件

28.SV：post chat-event (event_type=chat_mid_instruct) → SE，SV 执行 post 元语，生成用户侧通知事件

29.CC：on chat-event (event_type=mid_instruct)，【CC 内部】执行 mid_instruct 内部指令数组

30.CC：post chat-event (event_type=mid_output) → SV，CC 执行 post 元语，提交中间执行输出

31.SV：on chat-event (event_type=mid_output)，SV 执行 on 元语捕获事件，进入路由处理

32.SV：forward chat-event (event_type=mid_output) → CDT，SV 执行 forward 元语，原始执行结果回传 CDT 用于推演循环

33.SV：post chat-event (event_type=chat_mid_output) → SE，SV 执行 post 元语，生成用户侧中间结果通知事件

34.CDT：on chat-event (event_type=mid_output)，【CDT 内部】接收 mid_output，完成分析计算，判定是否继续循环推演：若仍需继续，回到第25步；若推演完成，进入第35步生成最终指令。

35.CDT：post chat-event (event_type=fin_instruct) → SV，CDT 执行 post 元语，投递终态机器指令事件，回填 session_id

36.SV：on chat-event (event_type=fin_instruct)，SV 执行 on 元语捕获事件，进入路由处理

37.SV：forward chat-event (event_type=fin_instruct) → CC，SV 执行 forward 元语中转转发原始指令事件

38.SV：post chat-event (event_type=chat_fin_instruct) → SE，SV 执行 post 元语，生成用户侧终态任务启动通知事件

39.CC：on chat-event (event_type=fin_instruct)，【CC 内部】执行 fin_instruct 内部最终指令数组
