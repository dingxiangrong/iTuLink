### 102.3.6.2 接口 path 定义

每个 path 对应一项独立接口。

•    upp-meta-get：获取UPP元数据

•    upp-cc-enum：容器枚举

•    cc-meta-get：获取容器元数据

•    cc-cap-enum：能力枚举

•    cc-cap-desc：能力描述

•    cc-cap-ctx：获取能力上下文

> **公共约束**:
> 1. 请求参数携带 session_id；应答参数回填同源 session_id。
> 2. 请求与应答一一配对。
> 3. 本组为查询只读接口，不触发 CDT 意图推演，不改变主任务流程状态。
