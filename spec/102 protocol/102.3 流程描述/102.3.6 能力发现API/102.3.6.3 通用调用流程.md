### 102.3.6.3 通用调用流程

1. SV：`call cc?xxx?yyy (调用参数)`，执行 call 元语发起接口调用。
2. CC：`on(事件报文)`，捕获该 call 报文，【CC 内部】执行对应接口业务逻辑，组装应答参数。
3. CC：on 处理完成，同步输出应答报文回传给 SV（应答为 on 的返回结果，不发起新的元语调用）。
4. SV：接收 call 应答报文，【SV 内部】解析应答结果，用于路由与事件翻译处理；**应答报文不进入 SV 的 on 入口**。

说明：
异常场景：异常信息放置于应答参数之内，调用链路保持不变。
触发时机：SV 处理上游各类交互过程中按需发起调用；会话全生命周期均可调用，支持并发，依靠 session_id 完成会话隔离。
本组接口原生交互链路仅存在 SV 与 CC 之间。
