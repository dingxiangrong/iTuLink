### 102.4.3.12 notify chat-fin-instruct

**元语签名**：notify(reqMsg: ReqMsg, payload: ChatFinInstructParams, ctrlMap?: CtrlMap) -> ResMsg

- reqMsg：原始请求消息实例，用于提取标识，生成本回调报文的 correlation_id

**生产者**：SV
**契约消费者**：SE
**描述**：notify 为点对点异步推送元语，用于推送 reqMsg 所指代请求在处理过程中的中间进度通知。SV 生成，面向用户侧终态任务启动通知。

**请求 payload**
```
{
  "sessionId": "string",
  "conversationId": "string",
  "chatId": "string",
  "event_type": "chat_fin_instruct",
  "notify_text": "string"
}
```

**响应 payload**
```
{
  "ret_code": "string",
  "ret_msg": "string"
}
```

**约束**

1. 本元语为异步投递契约，响应仅确认 SE 收到终态通知消息；终态任务执行完成的业务结果，由后续事件推送。
2. ret_code="0000"：SE 成功接收通知；非 0 代表投递 / 校验失败，SV 可重试推送。
3. notify_text：面向用户可读的终态任务启动提示文本。
4. event_type 固定取值 chat_fin_instruct。
5. 仅作用于当前 chatId 对应的任务链路，不修改 session、conversation 顶层生命周期。
6. notify 可连续多次推送；当收到对应 correlation_id 的 return 报文后，该 correlation_id 后续 notify 报文全部丢弃。
7. header.deadline 取自 ctrlMap 配置；ctrlMap 不传时 deadline 默认等于 0，表示无超时限制。接收方处理前校验 header.deadline，超时直接丢弃本条 notify 报文。
