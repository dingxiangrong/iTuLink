### 102.4.3.13 post fin-output

**元语签名**：post (destEp: Endpoint, path: "chat-event", payload: FinOutputParams, ctrlMap?: CtrlMap) -> ResMsg

- destEp：目标端点，此处为 SV 实例对应的 Endpoint 对象。

**生产者**：CC

**契约消费者**：SV

**描述**：CC 执行完毕，终态结构化输出；SV 接收，依据备份开关决定是否副本投递 CDT。

**请求 payload**
```
{
  "sessionId": "string",
  "conversationId": "string",
  "chatId": "string",
  "event_type": "fin_output",
  "action_id": "string",
  "final_result": {}
}
```

**响应说明**：
```
{
  "ret_code": "string",
  "ret_msg": "string"
}
```

**约束**

1. 本元语为异步投递契约，on 就绪回执仅确认 SV 收到终态输出消息；结果后续分发、业务闭环状态，由下游 emit 事件推送。
2. ret_code="0000"：SV 成功接收 fin_output；非 0 代表投递 / 校验失败，CC 可重试推送。
3. action_id：匹配对应 fin_instruct 下发的目标动作标识，一一对应。
4. final_result：CC 执行终态动作产生的结构化业务结果载荷。
5. SV 收到后，按系统备份开关配置，判断是否将本条结果副本投递至 CDT。
6. event_type 固定取值 fin_output。
7. 标志当前 chatId 任务链路执行结束；不销毁 session、conversation 顶层上下文。
