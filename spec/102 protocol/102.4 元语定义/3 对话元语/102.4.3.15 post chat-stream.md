### 102.4.3.15 post chat-stream

**元语签名**：post (destEp: Endpoint, path: "chat-event", payload: ChatStreamParams, ctrlMap?: CtrlMap) -> ResMsg

- destEp：目标端点，此处为 SE 实例对应的 Endpoint 对象。

**生产者**：CDT

**契约消费者**：SE

**描述**：实时流式分片推送事件，分片文本输出，供 SE 流式渲染。

**请求 payload**

```
{
  "sessionId": "string",
  "conversationId": "string",
  "chatId": "string",
  "event_type": "chat_stream",
  "fragment_text": "string",
  "is_end": false
}
```

**响应说明**：
```
{
  "ret_code": "string",
  "ret_msg": "string"
}
```

**约束**

1. 本元语为异步投递契约，on 就绪回执仅确认 SE 收到分片消息；流式输出全部完成的业务状态由后续事件识别。
2. ret_code="0000"：SE 成功接收本条分片；非 0 代表投递 / 校验失败，CDT 可重试推送。
3. fragment_text：单条分片的用户可读文本；多段分片按事件顺序依次推送。
4. is_end：布尔标记，true 代表当前 chatId 对应的流式输出全部分片推送完毕；false 代表还有后续分片。
5. event_type 固定取值 chat_stream。
6. 仅作用于当前 chatId 任务链路，不修改 session、conversation 顶层生命周期。
