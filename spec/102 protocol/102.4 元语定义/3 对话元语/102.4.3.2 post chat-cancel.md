### 102.4.3.2 post chat-cancel

**元语签名**：`post (destEp: Endpoint, path: "chat-cancel", payload: ChatCancelParams, ctrlMap?: CtrlMap) -> ResMsg`
- destEp：目标端点，此处为 CDT 实例对应的 Endpoint 对象。
**生产者**：SE
**契约消费者**：CDT

**描述**：对话任务终止指令，SE 向 CDT 下发，请求停止指定 chat 任务。ret_code 仅标识消息投递 CDT 结果，非业务终止结果。CDT 收到后，依据自身任务状态判断，按需通知对应 CC 停止执行；仅销毁 chatId 任务上下文，不改动 session、conversation 上下文。

**请求 payload**：

```
{
  "sessionId": "string",
  "conversationId": "string",
  "chatId": "string",
  "event_type": "chat_cancel"
}
```

**响应说明**：
```
{
  "ret_code": "string",
  "ret_msg": "string"
}
```

**约束**

1. 本元语为异步投递契约：on 就绪回执仅确认 CDT 收到消息、完成入队，不代表任务终止执行完成。任务终止完成状态通过后续 emit 事件元语推送。
2. ret_code 含义：
   - 0000：CDT 成功接收本条 chat_cancel 消息，已入队，开始异步处理。
   - 非 0 错误码：消息校验失败 / 存储失败，CDT 未接收，业务可选择重试。
3. chatId 为待终止任务的唯一标识，用来定位目标对话任务。
4. event_type 固定取值 chat_cancel，用于 CDT 识别事件类型。
5. sessionId、conversationId 为会话、对话层级独立标识，与 chatId 分属不同生命周期；取消操作不销毁 session、conversation 上下文。
