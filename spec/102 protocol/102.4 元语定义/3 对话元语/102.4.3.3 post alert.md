### 102.4.3.3 post alert

**元语签名**：post (destEp: Endpoint, path: "chat-event", payload: AlertParams, ctrlMap?: CtrlMap) -> ResMsg
- destEp：目标端点，此处为 SE 实例对应的 Endpoint 对象。

**生产者**：CDT

**契约消费者**：SE

**描述**：风险告警事件，人工干涉子流程；向用户输出风险提示，当前任务挂起，等待回执。

**请求 payload**

```
{
  "sessionId": "string",
  "conversationId": "string",
  "chatId": "string",
  "event_type": "alert",
  "alert_level": "string",
  "alert_text": "string"
}
```

**响应说明**：
```
{
  "ret_code": "string",
  "ret_msg": "string"
}
```

**约束**
1. 本元语为异步投递契约，on 就绪回执仅确认 SE 收到告警消息；任务挂起、人工回执处理结果，通过后续 emit 事件推送。
2. ret_code="0000"：SE 成功接收告警消息；非 0 代表投递 / 校验失败，CDT 可重试推送。
3. 收到本告警后，chatId 绑定的当前任务进入挂起状态，等待人工回执，不销毁 session、conversation 上下文。
4. event_type 固定取值 alert。
5. alert_level：告警分级标识；alert_text：面向用户可读的风险提示文本。
