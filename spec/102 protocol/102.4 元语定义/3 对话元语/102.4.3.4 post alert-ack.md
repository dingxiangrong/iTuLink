102.4.3.4 post alert-ack
**元语签名**：post (destEp: Endpoint, path: "chat-event", payload: AlertAckParams, ctrlMap?: CtrlMap) -> ResMsg
- destEp：目标端点，此处为 CDT 实例对应的 Endpoint 对象。
**生产者**：SE
**契约消费者**：CDT
**描述**：告警业务回执，代表用户已经阅知告警，不带选择参数。
**请求 payload**
```
{
  "sessionId": "string",
  "conversationId": "string",
  "chatId": "string",
  "event_type": "alert_ack"
}
```

**响应说明**：
```
{
  "ret_code": "string",
  "ret_msg": "string"
}
```

**约束**

1. 本元语为异步投递契约，on 就绪回执仅确认 CDT 收到回执消息；任务恢复执行的状态通知，由后续 emit 事件推送。
2. ret_code="0000"：CDT 成功接收告警回执；非 0 代表投递或校验失败，SE 可重试。
3. 回执仅表达用户阅知告警，不携带业务选择参数，CDT 收到后恢复对应 chatId 任务流转。
4. event_type 固定取值 alert_ack。
5. 必须匹配已存在且处于挂起状态的 chatId，不存在或状态不匹配返回错误码。
