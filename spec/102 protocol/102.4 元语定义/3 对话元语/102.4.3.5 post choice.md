### 102.4.3.5 post choice

**元语签名**：post (destEp: Endpoint, path: "chat-event", payload: ChoiceParams, ctrlMap?: CtrlMap) -> ResMsg

- destEp：目标端点，此处为 SE 实例对应的 Endpoint 对象。

**生产者**：CDT

**契约消费者**：SE

**描述**：冲突抉择提示事件；向用户抛出可选项，任务挂起，等待用户 choose 回执。

**请求 payload**
```
{
  "sessionId": "string",
  "conversationId": "string",
  "chatId": "string",
  "event_type": "choice",
  "option_list": [
    {
      "option_id": "string",
      "option_label": "string",
      "option_desc": "string"
    }
  ]
}
```

**响应说明**：
```
{
  "ret_code": "string",
  "ret_msg": "string"
}
```

**约束**

1. 本元语为异步投递契约，on 就绪回执仅确认 SE 收到抉择提示消息；用户选择回执、任务继续流转的状态，由后续元语完成。
2. ret_code="0000"：SE 成功接收 choice 事件；非 0 代表投递 / 校验失败，CDT 可重试推送。
3. 收到本事件后，chatId 对应的任务进入挂起状态，等待用户选择回执；session、conversation 上下文保持保留。
4. event_type 固定取值 choice。
5. option_list：候选选项集合，option_id 作为后续回执引用的唯一标识；option_label 为用户可读选项名称，option_desc 为选项语义说明。
