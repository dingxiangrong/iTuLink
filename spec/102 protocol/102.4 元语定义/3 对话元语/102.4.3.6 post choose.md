### 102.4.3.6 post choose

**元语签名**：post (destEp: Endpoint, path: "chat-event", payload: ChooseParams, ctrlMap?: CtrlMap) -> ResMsg

- destEp：目标端点，此处为 CDT 实例对应的 Endpoint 对象。

**生产者**：SE

**契约消费者**：CDT

**描述**：用户抉择返回事件，携带用户选择结果；CDT 收到后恢复挂起推演断点。

**请求 payload**
```
{
  "sessionId": "string",
  "conversationId": "string",
  "chatId": "string",
  "event_type": "choose",
  "selected_option": "string"
}
```

**响应说明**：
```
{
  "ret_code": "string",
  "ret_msg": "string"
}
```

**约束**

1. 本元语为异步投递契约，on 就绪回执仅确认 CDT 收到选择回执，推演断点恢复的业务状态，由后续 emit 事件推送。
2. ret_code="0000"：CDT 成功接收选择回执；非 0 代表投递 / 校验失败，SE 可重试。
3. selected_option：对应上游 choice 元语下发的 option_id。
4. 仅当 chatId 任务处于挂起状态时，回执生效；任务状态不匹配返回错误码。
5. event_type 固定取值 choose。
