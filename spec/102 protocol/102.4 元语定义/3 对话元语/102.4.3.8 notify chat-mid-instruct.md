### 102.4.3.8 notify chat-mid-instruct

**元语签名**：notify (destEp: Endpoint, path: "chat-event", payload: ChatMidInstructParams, ctrlMap?: CtrlMap) -> ResMsg

- destEp：目标端点，此处为 SE 实例对应的 Endpoint 对象。

**生产者**：SV

**契约消费者**：SE

**描述**：SV 生成，面向用户侧的中间任务启动通知事件。

**请求 payload**

```
{
  "sessionId": "string",
  "conversationId": "string",
  "chatId": "string",
  "event_type": "chat_mid_instruct",
  "notify_text": "string"
}
```

**响应说明**：
```
{
  "ret_code": "string",
  "ret_msg": "string"
}
```

**约束**

1. 本元语为异步投递契约，就绪回执仅确认 SE 收到通知消息；中间任务执行状态变化由后续 emit 事件推送。
2. ret_code="0000"：SE 成功接收通知；非 0 代表投递 / 校验失败，SV 可重试推送。
3. notify_text：面向用户可读的中间任务启动提示文本。
4. event_type 固定取值 chat_mid_instruct。
5. 仅作用于当前 chatId 对应的任务链路，不修改 session、conversation 顶层生命周期。
