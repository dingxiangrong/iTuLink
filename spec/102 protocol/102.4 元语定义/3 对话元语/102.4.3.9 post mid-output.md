### 102.4.3.9 post mid-output

**元语签名**：post (destEp: Endpoint, path: "chat-event", payload: MidOutputParams, ctrlMap?: CtrlMap) -> ResMsg

- destEp：目标端点，此处为 CDT 实例对应的 Endpoint 对象。

**生产者**：CC

**契约消费者**：CDT

**描述**：CC 中间指令执行完成输出结果，回送给 CDT，供继续循环推演。

**请求 payload**

```
{
  "sessionId": "string",
  "conversationId": "string",
  "chatId": "string",
  "event_type": "mid_output",
  "action_id": "string",
  "output_data": {}
}
```

**响应说明**：
```
{
  "ret_code": "string",
  "ret_msg": "string"
}
```

**约束**

1. 本元语为异步投递契约，on 就绪回执仅确认 CDT 收到中间输出消息；后续推演流转结果由下游事件推送。
2. ret_code="0000"：CDT 成功接收中间输出；非 0 代表投递 / 校验失败，CC 可重试推送。
3. action_id：标记本条输出对应的目标动作标识，与 mid_instruct 下发的单条 action_id 一一匹配。
4. output_data：CC 执行指令产生的业务输出载荷，与对应 mid_instruct 的 action 动作规格匹配。
5. event_type 固定取值 mid_output。
6. 本事件仅作用于当前 chatId 任务链路，不改动 session、conversation 顶层生命周期。
