### 103.3.3 业务场景推演示例（商机报告填报）

#### 3.3.1 场景说明

用户指令：帮我填写一份客户商机报告，包含 XXX 客户信息、PP1/PP2 产品应用情况、PP1/PP2 产品招标测算。

| 动作项 | 命名             | dependsActions（候选模板）   |
| --- | -------------- | ---------------------- |
| AC1 | 客户主数据检索        | []                     |
| AC2 | 产品主数据检索        | []                     |
| AC3 | 商机报告表单填报（目标动作） | [AC1（客户检索）, AC2（产品检索）] |

实际依赖推演（候选模板 + 用户输入动态过程）：

 用户输入提及 1 个客户（XXX）→ 实例化 1 个 AC1；

 用户输入提及 2 个产品（PP1、PP2）→ 实例化 2 个 AC2（AC2a、AC2b）；

 AC3 实际 depend_list = [AC1, AC2a, AC2b]。

反例：若用户本次未提及产品，实际 depend_list = [AC1]，产品检索不进入本轮依赖。

#### 3.3.2 CDT 推演过程

1. 目标识别：CDT 解析用户输入 “填报商机报告”，命中目标 Action AC3；AC1、AC2 用户未提及、也无法感知，仅存在于 AC3 依赖模板中；

2. 依赖推演：CDT 读取 AC3.dependsActions 候选模板，展开候选依赖 AC1（客户检索）、AC2（产品检索）；结合用户输入上下文实例化 —— 提及 1 客户（XXX）→ AC1×1，提及 2 产品（PP1、PP2）→ AC2×2；AC3 实际 depend_list = [AC1, AC2a, AC2b]；

3. 递归展开：对每个实际依赖项递归解析其 dependsActions（本场景 AC1、AC2a、AC2b 均无下层依赖，闭包即这三个节点）；

4. 层次调度执行：同层平行依赖 AC1、AC2a、AC2b 无顺序要求，可并行或按调度策略执行；每完成一个依赖项，CDT 检查其后续节点（successor）中 AC3 尚未就绪 → post mid_instruct，压入 instruct stack；

5. 依赖闭包满足：AC1、AC2a、AC2b 全部完成，AC3 前置依赖全部就绪；

6. 执行 AC3：商机报告表单填报（客户信息、PP1/PP2 应用情况、招标测算）；

7. 输出判定：AC3 完成后，无未决后续节点 → post fin_AC3（即 fin_instruct），本轮推演闭环结束。

**依赖树表达**:
```
AC3（目标动作）
├── AC1（客户主数据检索 × 1）
│  └── …（AC1 的依赖，若存在则递归展开为下一层）
├── AC2a（产品主数据检索 · PP1）
│  └── …
└── AC2b（产品主数据检索 · PP2）
    └── …
```

#### 3.3.3 示例逻辑收口

推演以目标 Action 为入口，依赖闭包递归展开，非拓扑排序平铺、非先执行再补依赖；

dependsActions 仅为静态候选模板，实际依赖由用户输入动态推演：未提及不进入，提及几个实例化几个；

所有 Action 地位平等，无主 / 旁之分；本轮谁进入实际 depend_list 由用户输入命中 + 依赖链展开决定；

用户输入仅命中目标 Action 并提供实例化上下文；被依赖 Action 由 CDT 递归推演自动展开，对用户透明；

平行依赖项之间无顺序要求，同层可并行或按调度策略执行；深层依赖必须先于其直接后继满足；

依赖项完成 → mid_instruct；目标动作完成 → fin_instruct；

递归展开遇已存在路径中的 Action → 循环依赖，CDT 报错，不进入执行。

#### 3.3.4 推演描述脚本

标准执行流程脚本：CDT 调度目标 AC3 → 读 AC3.dependsActions，实例化展开得到实际 depend_list = [AC1, AC2a, AC2b] → 循环遍历 depend_list，逐项执行 → 每项如果有自己的 dependsActions，递归展开 → 叶子节点直接执行 → depend_list 全部完成 → 执行 AC3 → post fin_AC3

**完整推演脚本**：
```
推演开始：用户输入「填报商机报告」 CDT 调度目标 AC3
├─ 检查 AC3 依赖推演
│    发现并行依赖：1 个 AC1（客户主数据检索）、2 个 AC2（产品主数据检索 · PP1/PP2）
│    追加 AC3 实际 depend_list = [AC1, AC2a, AC2b]
├─ CDT 循环执行 AC3 实际 depend_list
│    ├─ 执行依赖项 AC1，递归
│    │     AC1 无依赖 → 执行完成 → post mid_instruct（后续节点 AC3 未就绪），压栈
│    ├─ 执行依赖项 AC2a，递归
│    │     AC2a 无依赖 → 执行完成 → post mid_instruct，压栈
│    └─ 执行依赖项 AC2b，递归
│           AC2b 无依赖 → 执行完成 → post mid_instruct，压栈
│    依赖闭包全部满足 → AC3 就绪
├─ 执行 AC3（商机报告表单填报）
└─ post fin_AC3（即 fin_instruct），本轮推演闭环结束
```
