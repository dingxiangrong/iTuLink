### 103.4.1 语义主体（SemanticSubject）

体系内所有可被寻址、可被定义的语义对象，全部派生自该顶层抽象主体，统一基础属性。

| 字段名          | 类型  | 是否必选 | 说明                                                                         |
| ------------ | --- | ---- | -------------------------------------------------------------------------- |
| id           | 标识符 | 必选   | 机器全局唯一标识，非人读                                                               |
| name         | 字符串 | 必选   | 给人看的名称                                                                     |
| desc         | 字符串 | 必选   | 给人阅读的描述                                                                    |
| icon         | 字符串 | 必选   | 图标标识                                                                       |
| semanticDesc | 字符串 | 必选   | 给 AI（CDT），完整语义说明，供认知推演单元做意图匹配、能力推理使用                                       |
| version      | 字符串 | 可选   | 版本号，无则置空。version 为对象语义版本，建议遵循语义化版本 SemVer；本规范不强制规定多版本共存的兼容策略，由上层调用方处理版本差异。 |
