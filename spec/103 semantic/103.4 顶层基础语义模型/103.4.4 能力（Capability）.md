### 103.4.4 能力（Capability）

**继承**：语义主体（SemanticSubject）  
业务能力语义定义主体，全权管理下属所有动作项。Capability 对应 102 范式中的「能力单元」；继承自 SemanticSubject 的 id、name、desc、icon、semanticDesc、version，即为 102 定义的静态展示元信息来源。

| 字段名             | 类型                       | 是否必选 | 说明                                                                                                                                                                              |
| --------------- | ------------------------ | ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| capabilityType  | 枚举                       | 必选   | UI = 有界面能力 / Headless = 无界面能力。UI 对应 102「带界面能力（ui-cap）」；Headless 对应 102「开放式无界面能力（func-cap）」；UI 类型强制 stateMode=Stateful。                                                          |
| stateMode       | 枚举                       | 必选   | Stateful = 有状态 / Stateless = 无状态；UI 类型强制为 Stateful                                                                                                                              |
| input           | InputParamSpec[]         | 可选   | 平行输入参数集合，空数组代表无输入                                                                                                                                                               |
| output          | OutputSpec｜null          | 可选   | 顶层输出封装结构，null 代表无输出                                                                                                                                                             |
| completionCheck | CompletionCheckSpec｜null | 可选   | 无状态能力完成检测契约                                                                                                                                                                     |
| synonyms        | string[]                 | 可选   | 语义目标标签集合。 1. 意图解析：用户输入命中 name 或任意词条，匹配本能力； 2. 试错纠偏：本能力执行失败时，CDT 使用本组标签，全局查找拥有任意一个重叠词条的其它能力，动态生成等价备选候选池； 候选池排序、过滤、重试控制由下游 CDT 实现层负责；本元模型仅存储标签，不维护硬对象引用；支持单个实体携带多组目标词条，天然兼容多语义场景。 |

**包含关系**：持有若干动作项（Action）  

> **补充说明**： 能力的 input/output 为能力级规格；动作项的 input/output 为该动作项私有规格。 两者合并、覆盖、叠加规则由下游实现层定义，本语义层不做约束。
