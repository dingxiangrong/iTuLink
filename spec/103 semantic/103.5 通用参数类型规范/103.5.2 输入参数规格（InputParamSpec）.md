### 103.5.2 输入参数规格（InputParamSpec）

输入参数为纯平行扁平结构，元模型层面禁止任何嵌套。

| 字段名      | 类型        | 是否必选 | 说明      |
| -------- | --------- | ---- | ------- |
| name     | 字符串       | 必选   | 参数唯一名称  |
| desc     | 字符串       | 必选   | 参数语义描述  |
| type     | ParamType | 必选   | 参数类型    |
| required | 布尔        | 必选   | 是否为必填参数 |

**说明**：当 type=FileDescriptor 时，该参数传递文件元描述信息；原始文件二进制流不属于本语义元模型范畴，归属传输实现层。
