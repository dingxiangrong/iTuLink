### 103.5.3 业务载荷树形规格（OutputParamSpec）

用于描述 payload 内部业务本体树形结构，支持 children /items 递归嵌套，适配对象、数组、多层复杂业务结构。

| 字段名      | 类型                | 是否必选 | 说明                        |
| -------- | ----------------- | ---- | ------------------------- |
| name     | 字符串               | 必选   | 输出节点名称                    |
| type     | ParamType         | 必选   | 参数类型                      |
| desc     | 字符串               | 可选   | 节点语义描述                    |
| children | OutputParamSpec[] | 可选   | type=object 时生效，定义对象子节点集合 |
| items    | OutputParamSpec   | 可选   | type=array 时生效，定义数组元素模板   |

**补充说明**： 本业务载荷规格不设置 required 字段。输出为能力对外承诺返回的业务结构；子字段可选与否，由对应能力的业务文档补充约定。
