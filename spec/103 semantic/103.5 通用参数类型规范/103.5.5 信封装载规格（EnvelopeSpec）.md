### 103.5.5 信封装载规格（EnvelopeSpec）

信封专属扁平结构，用于承载调用链路状态、协议应答、追踪信息等非业务过程字段，不使用树形递归结构。

| 字段名       | 类型            | 是否必选 | 说明                                   |
| --------- | ------------- | ---- | ------------------------------------ |
| code      | number｜string | 可选   | 应答状态码                                |
| message   | string        | 可选   | 应答描述信息                               |
| requestId | string        | 可选   | 请求唯一标识                               |
| traceId   | string        | 可选   | 链路追踪标识                               |
| extend    | object        | 可选   | 键值对形式，键为过程字段名、值为任意类型；用于承载未预定义的过程扩展字段 |

**说明**： extend 仅存放过程类扩展字段，禁止存放任何业务载荷数据，业务数据必须收敛至 payload。

**语义强约束**：

1. Envelope 所有字段为过程通信属性，不承载任何业务数据

2. 所有业务输出，必须收敛至 payload

3. 下游实现层不得在 payload 内存放过程字段
