# spec｜iTuLink 定义层 — 技术契约仓库

> 本目录存放 iTuLink **稳定、准予归档的规范、公理、范式契约文档**。
> spec 产出是全体系的技术基准；所有工程实现（impl）必须对齐本目录内的契约。
> 本目录**不存放工程详细设计、初稿、rev迭代修订稿**，此类文档归入 impl。

## 变更与归档规则
1. **存量归档文档**：已经准予归档的定稿文档，磁盘原始文件名不做修改，保障溯源；仅新撰写的 spec 文档使用上面的编号体系。
2. **修改流程**：发现实现与spec冲突，优先升级 spec 版本，再调整 impl 工程代码/设计；**禁止在impl绕过spec契约直接实现**。
3. **编号隔离提醒**：
   - spec内部 `0xx-5xx`：iTuLink自身技术契约编号；
   - `outreach/analysis` 的 `200-299` 属于**完全独立命名空间**，用于行业研判辨析文章，和本目录`2xx`核心模型编号互不关联，请勿混淆。
4. 本目录所有文档归档均遵循 A00：五道-一法 —— 人机协作原创确权范式。

## 上下游关系
